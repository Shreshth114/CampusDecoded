Two trust levels, never silently mixed

Personal uploads are unverified. Institutional evidence requires administrator review and explicit publication. Every query and cache is scoped to the selected workspace.

Model extracts, code decides

Exact quotes and numeric values are validated before rules enter the Rule Book. Confirmed facts are compared in deterministic code; missing facts, exceptions and conflicts prevent a confident verdict.

Path to Eligibility recomputes hypothetical numeric facts and threshold arithmetic locally in deterministic code, with zero model calls.

Optional MCP integration

A local stdio-only search_policies tool binds to one personal workspace. It reuses scoped retrieval and returns document/page passages; it exposes no institutional or administrative operations.

Choices and trade-offs

Local embeddings avoid embedding API cost but consume CPU. Chroma keeps deployment simple but this local prototype uses one writer process. HyDE adds an LLM call and may improve vocabulary matching; it must be evaluated on human-labelled queries. Quote checks verify wording, not complete semantic truth.
